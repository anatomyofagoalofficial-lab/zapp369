# Claude Code Skills (vendored)

These design skills are committed here so that **Claude Code on the web** auto-loads
them for every session on this repo (the web container is ephemeral, so anything not
committed disappears between sessions).

## Skills

- **ui-ux-pro-max** — UI/UX design intelligence (styles, palettes, font pairings,
  product types, UX guidelines, chart types). Primary skill for design work here.
- **design** — brand identity, design tokens, logos, icons, mockups, slides.
- **design-system** — token architecture + component specs.
- **brand** — brand voice, visual identity, messaging.
- **banner-design** — social/ads/web/print banners.
- **slides** — strategic HTML presentations.
